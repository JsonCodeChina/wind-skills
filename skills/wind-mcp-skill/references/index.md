# `index_data` 工具契约

只用于指数和板块。参数名称、类型、必填项、默认值和枚举以本文件各工具的契约为准。

- `indexes` 逐字取自本文件的「`indexes` 行情指标」。
- 已确认的标准代码可直接传，例如 `000300.SH`、`HSI.HI`；不得猜测未知后缀。

### `get_index_quote`

获取指数在显式日期范围内的分钟级行情时间序列。每条记录代表一分钟，包含：价格、均价、成交量、换手率。当用户需要日内价格走势、逐分钟交易数据或任何日内时间序列数据时，使用此工具。

| 参数 | 必填 | 类型 | 枚举 | 默认值 | 官方说明 |
| --- | --- | --- | --- | --- | --- |
| `windcode` | 是 | string | — | — | 指数名称或者指数代码，如沪深300或000300.SH |
| `begin_date` | 是 | string | — | — | 查询开始日期，格式 yyyy-MM-dd；不支持隐式默认值。 |
| `end_date` | 是 | string | — | — | 查询结束日期，格式 yyyy-MM-dd；不支持 `LAST` 或隐式默认值。 |

### `get_index_price_indicators`

获取一个或多个指数的某一具体价格指标的最新快照值。需要提供指数或板块代码和指标名称（如：开盘价、最高价、最低价、收盘价、成交量）。返回单一当前值，而非时间序列。当用户询问一个或多个指数的当前/最新价格或任何单一指标值时，使用此工具。
