## 3. 失败明细

### 用例 076

- 工具：`economic_data.natural_language_get_edb_data`
- 问题：搜索并提取中国新能源汽车产量从 2025-01-02 到 2025-12-31 的数据
- 错误码：`1008`
- 错误信息：指标访问受限
- 判断：权限或数据授权问题。建议确认当前账号是否具备对应 EDB 指标权限。

### 用例 081

- 工具：`economic_data.natural_language_get_edb_data`
- 问题：搜索并提取中国 GDP 从 2026-01-05 到 2026-06-30 的数据
- 错误码：`200`
- 错误信息：部分年度 GDP 指标在指定时间范围内没有数据
- 补充现象：返回内容中季度 GDP 指标存在 2026-03-31 和 2026-06-30 数据，但年度指标没有该区间数据，导致整体调用按错误处理。
- 判断：数据频率与查询时间范围不匹配。建议 EDB 层允许部分指标成功返回，或在生成用例时根据指标频率选择日期范围。
